# Product Overview

## 競馬予想＋投資管理アプリ (Keiba Mobile App)

A mobile-optimized horse racing prediction and investment management application built with React and TypeScript. The app enables users to analyze horse racing data, generate predictions using sophisticated algorithms, and track their betting investments and returns.

## Core Features

- **Horse Racing Predictions**: Advanced prediction engine using speed indices, recent form, and odds analysis
- **Investment Tracking**: Comprehensive betting record management with profit/loss calculations
- **Statistical Analysis**: Detailed accuracy tracking, trend analysis, and performance metrics
- **Mobile-First Design**: Touch-optimized interface with responsive design for smartphones
- **PWA Support**: Progressive Web App capabilities for offline usage and app-like experience
- **Data Management**: Local storage with IndexedDB for persistent data and offline functionality

## Target Users

- Horse racing enthusiasts who want data-driven predictions
- Bettors seeking systematic investment tracking and analysis
- Mobile users who need on-the-go access at racing venues

## Key Value Propositions

1. **Scientific Approach**: Algorithm-based predictions using multiple data points
2. **Investment Discipline**: Systematic tracking of betting performance and ROI
3. **Mobile Convenience**: Optimized for use at racing tracks with offline capabilities
4. **Performance Insights**: Detailed analytics to improve prediction accuracy over time

## Future Roadmap

- iOS native app development using Capacitor
- Enhanced data synchronization and cloud backup
- Advanced machine learning prediction models
- Social features for sharing predictions and results

## Development Communication

**Language Preference**: All development progress updates, explanations, and communications should be conducted in Japanese (日本語) when working on this project. This includes:

- Code comments and documentation
- Progress reports and status updates
- Feature explanations and technical discussions
- Error messages and debugging information
- User interface text and labels

This ensures consistency with the target Japanese market and facilitates better communication with the development team.
